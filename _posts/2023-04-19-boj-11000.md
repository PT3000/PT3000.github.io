1. 현재 강의실 시간, 이전 강의실 시간을 기록한다.
2. 강의실을 큐로 받아와서 현재 받아온 큐와 다음 받아온 큐를 비교한다.
3. 작거나 같으면, 카운트를 한번만 하고 연속 강의실 여부를 검사했으므로 바꾼다. 이후 반복될 때 또 같은 조건이면, 최소 강의실을 구하는 거기 때문에 카운트를 하지 않는다. (카운트볼=False이기 때문에 카운트 되지 않는다.)
4. 그리고 만약 작거나 같지 않으면, 두 번째 큐에 값을 집어넣는다. ( 다른 강의실에 배치되지만, 이 또한 연속될 수 있기 때문이다.)
5. 그리고 계속 반복한다.
6. 만약 반복하다가 현재 강의실 시간보다 크다면, 이전 기록한 강의실 시간으로 갈 것이다. 여기서도 작거나 같은지 검사한다.
7. 만약에 작거나 같으면, 여기서도 카운트볼2을 True에서 False로 바꿔준다. 원리는 같다.
8. 만약 작거나 같지 않으면, 값을 바꿔준다. (여기세서 카운트를 해준다.) → 만약 7번에서 하면 겹치기 때문에, 교실이 바뀔 때, 연속한 교실을 계속 탐색하다가, 교실이 바뀔 때 카운트를 해주는 것이 좋다.

제가 이해하기로는, 이 코드의 시간 복잡도는 $O(n\log n)$입니다.

우선 입력받은 강의들을 강의 시작 시간을 기준으로 정렬합니다. 그 다음, PriorityQueue를 사용하여 첫 번째 강의의 종료 시간을 큐에 넣고 시작합니다. 그리고 반복문을 통해 각각의 강의에 대해 차례대로 검사합니다. 강의 시작 시간이 큐의 맨 앞 강의 종료 시간보다 빠르면, 새로운 강의실을 생성합니다. 아니면, 기존 강의실을 사용합니다. 이때, 큐에는 각 강의실의 종료 시간만 저장하게 됩니다.

따라서, 정렬하는데 $O(n \log n)$의 시간이 걸리고, 각각의 강의에 대해 큐에 삽입/삭제 연산이 일어나므로, 전체적으로 $O(n \log n)$의 시간복잡도를 가지게 됩니다.

```python
from queue import PriorityQueue

# 입력 받기
n = 4
lectures = [(1, 5), (1, 3), (5, 7), (3, 6)]

# 시작 시간을 기준으로 정렬
lectures.sort()

# 우선순위 큐를 사용하여 강의실 배정
q = PriorityQueue()
q.put(lectures[0][1])
for i in range(1, n):
    # 현재 강의의 시작 시간이 큐의 맨 앞의 강의 종료 시간보다 이른 경우
    if lectures[i][0] < q.queue[0]:
        q.put(lectures[i][1]) # 새로운 강의실 생성
    # 현재 강의의 시작 시간이 큐의 맨 앞의 강의 종료 시간보다 늦은 경우
    else:
        q.get() # 기존 강의실 사용
        q.put(lectures[i][1])

print(q.qsize()) # 필요한 강의실의 개수 출력

# 출력: 2


```
