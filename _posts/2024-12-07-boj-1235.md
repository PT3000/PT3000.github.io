## 풀이

- 학생번호의 길이는 알 수 없다. → 그러므로 길이는 가변적으로 받아야 한다.(벡터 사용)
- 맨 뒷자리의 번호를 순회를 돈다.
- 순회를 돌때, 같은 번호가 있으면, 순회를 멈추고 십의 자리, 백의 자리 이런식으로 이동한다.
- 이동할때, n의 자리 뿐만이 아닌, 밑의 자리까지 다 포함하여 같은 숫자가 있는지 비교한다.
- 같은 숫자가 없으면, 멈추고 k값을 출력한다.

### 코드 동작 방식

- 학생번호 n을 전체 순회를 돈다.
- 첫번째 줄 맨 뒷자리 번호를 순회를 돈다.
- 순회가 끝났을 때, 같은 번호가 없으면 두 번째줄부터 다시 순회를 돈다.
- 같은 숫자가 나오면, 멈추고 정답을 출력한다.

## 코드(실패한 코드)

```cpp
#include <iostream>
#include <vector>
#include <string>

using namespace std;
int main() {
    int n = 0;
    string number; // 학생번호
    cin >> n;
    int correct = 0;
    vector<string> student;
    int len = 0; // 학생번호 길이
    bool a = false;
    int count = 0;
    
    for(int i = 0;i < n;i++) {
        cin >> number;
        len = number.length()-1;
        student.push_back(number);
    }
   for(int i = 0;i < len-1;i++) { // n의 자릿수를 순회
       if(a) {
            a = false;
        }
       if(count == n) {
           break;
       }
       correct += 1;
        for(int l = 0;l < n-2;l++) { // 같은 숫자가 나오지 않을 시, 다음 줄의 숫자를 나머지 숫자들과 비교
            if(a) {
                        a = false;
                        break;
                    }
            for(int j = l; j < n-1;j++) { // 학생번호를 순회
                if(a) {
                        break;
                    }
                for(int k = j+1;k < n;k++) { // 다음 학생번호를 순회
                    //cout << student[j].substr(len-i,len) << ":" << student[k].substr(len-i,len) << endl;
                    if(student[j].substr(len-i,len) == student[k].substr(len-i,len)) {
                        a = true;
                        count = 0;
                        break; // 같은 숫자가 나오면 다음 자릿수로 넘어가도 된다.
                    } else {
                        count += 1;
                    }
                }
            }
        }
    }

    cout << correct << endl;
    
    return 0;
}
```

## 코드(개선된 코드)

```cpp
#include <iostream>
#include <vector>
#include <string>
#include <set>

using namespace std;

int main() {
    int a = 0;
    int n = 0;
    string number; // 학생번호
    cin >> n;
    vector<string> student;
    int len = 0; // 학생번호 길이
    set <string> s;
    // 학생번호 입력받기
    for(int i = 0; i < n; i++) {
        cin >> number;
        len = number.length();
        student.push_back(number);
    }
    for(int i = 0; i < len; i++) { // n의 자릿수를 순회
        for(int k = 0;k < n; k++) { // n의 자릿수의 student를 set을 통해 생성
            s.insert(student[k].substr(len-i-1,len));
        if(s.size() == n) {
            cout << i+1 << endl;
            exit(0);
        }
        s.clear();
    }
    return 0;
}
```

- 처음에는 모든 순회를 돌며, 완전 브루트포스를 진행하려 했었지만, 시간초과로 인해 실패했다.
- 시간복잡도를 계산해보니 n의 4승이라 설사 된다 했더라도 너무 비효율적인 코드였다.
- 결국 정답을 참고하여, 중복제거를 할 수 있는 함수인 set 함수의 아이디어를 얻어 코드를 개선시킬 수 있었다.
