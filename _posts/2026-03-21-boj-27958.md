## 문제 설명

- *N*×*N* 크기의 보드 판이 존재하며, 1개 이상의 표적이 존재한다.
- 1번부터 *K*번까지 *K*개의 총알을 가지고 있다.
- 각각의 총알은 공격력을 가지고 있음(표적의 체력이 공격력보다 많으면 표적 제거 x)

## 풀이

- 이 문제는 총알을 쐈을 때, 어떤 순서로 점수판을 쐈을 때 최대 점수를 가질 수 있는지 판단하는 문제이다.
- 최대 점수인지 알기 위해서는 모든 경우의 수를 탐색해봐야 하기 때문에 백트래킹을 사용하여 분기별로 판단하여, 가장 큰 최대 점수를 구해야 한다.
- 백트래킹을 할 때, 체력이 깎이는 분기점이 있기 때문에 다음 분기 보드의 깊은 복사를 통하여 다음 분기보드에 백트래킹 함수를 보내어, 나뉘는 분기점의 보드를 계산한다.
- 계산한 다음, 분기 전의 보드로 돌아와 다시 적절한 해가 있는지 백트래킹한다.
- N x N 크기의 보드판에서 총알은 행 하나를 기준으로 왼쪽 → 오른쪽으로 가기 때문에 0을 제외한 표적을 만나면 로직을 수행한 뒤, break를 건다. → 그 행에서 표적을 만나면 다음 표적으로 가지 않기 때문이다.
- 보너스 표적인 경우
  - 보너스 표적인 경우에는 총알의 공격력과는 상관없이, 무조건 점수를 얻을 수 있기 때문에 표적의 체력과 계산할 필요가 없다.
  - 또한, 현재 위치의 체력을 기준으로 상,하,좌,우 분기점을 나눌 필요가 없기 때문에 계산하지 않는다.
  - 현재 위치를 다음 분기의 보드 위치에서 0으로 만들고 백트래킹한다.
- 일반 표적인 경우
  - 총알의 공격력 \< 표적의 체력
    - 총알의 공격력이 더 낮은 경우에는 표적을 지울 수 없기에 표적의 체력만 깎을 수 있다.
    - 그러나, 나중에 총알이 현재 위치의 표적을 지울 수 있다.
    - 지우면서, 현재 위치의 표적 위치를 기준으로 상,하,좌,우를 초기 체력 // 4로 정의하기 때문에 초기 체력의 값 또한 기억해야 한다.
    - 초기 체력의 값을 기억하기 위해서는 현재 보드 전체의 위치를 기억해야 하기 때문에 점수판 리스트 또한, 백트래킹으로 다음 분기마다 보내줘야 한다.
    - 값이 변하면, 점수보드판 또한 반영해야 한다.
  - 총알의 공격력 > 표적의 체력
    - 총알의 공격력이 표적의 체력보다 높으므로, 표적을 지울 수 있다.
    - 앞서 말했던 것처럼, 표적 위치를 기준으로 상,하,좌,우를 초기 체력 // 4로 정의하여, 각 표적의 점수를 변경한다.
    - 그러나, 값이 비어있는(0) 경우에만 변경이 가능하며, 보드의 index 범위를 넘어서 변경하는 것은 안되기 때문에 index 범위를 넘지 않도록 제한했다.
- count가 k번까지 오면, 현재까지의 score의 합을 구하여 correct보다 크다면, score의 합을 바꾼다.
- 최종적으로 가장 큰 score의 합이 나온다.

## 코드

```python
boardList = []
powerList = []
score = []
correct = -1
n = int(input())
k = int(input())
init_board = [list(map(int,input().split())) for _ in range(n)]
scoreBoard = [_[:] for _ in init_board] ## 초기 체력 저장 공간
power = list(map(int, input().split()))

def backtracking(count,board,scoreBoard) :
    global score, correct
    if count == k : ## k번 쐈을 때 다시 돌아와야 한다.
        if correct < sum(score) :
            correct = sum(score)
        return
    dx = [-1,1,0,0]
    dy = [0,0,-1,1]
    # 보드 변경 로직
    for i in range(n) :
        for j in range(n) :
            if board[i][j] > 9 : ## 보너스 점수인 경우
                score.append(board[i][j])
                nxt_board = [row[:] for row in board] ## 다음 분기 보드(깊은 복사)
                nxt_score = [row[:] for row in scoreBoard] ## 다음 분기 보드(깊은 복사)
                nxt_board[i][j] = 0
                nxt_score[i][j] = 0
                backtracking(count + 1, nxt_board, nxt_score)
                score.pop()
                break
            elif board[i][j] > 0 : #일반 점수인 경우
                nxt_board = [row[:] for row in board] ## 다음 분기 보드(깊은 복사)
                nxt_score = [row[:] for row in scoreBoard] ## 다음 분기 보드(깊은 복사)
                if board[i][j] > power[count] : # 표적의 체력이 총알보다 많을 때
                    nxt_board[i][j] = board[i][j] - power[count]
                    score.append(0) # 제거 못하는 경우가 있다
                else : # 표적이 사라진 경우
                    score.append(scoreBoard[i][j])
                    if board[i][j] // 4 > 0 : ## 새로운 표기 체력이 0보다 클 때만 실행.
                        for x,y in zip(dx,dy) :
                            nx = i + x
                            ny = j + y
                            if nx > -1 and nx < n and ny > -1 and ny < n and board[nx][ny] == 0 : # 비어 있는 공간에만 생성
                                nxt_board[nx][ny] = scoreBoard[i][j] // 4
                                nxt_score[nx][ny] = scoreBoard[i][j] // 4
                    nxt_board[i][j] = 0
                    nxt_score[i][j] = 0
                backtracking(count + 1, nxt_board, nxt_score)
                score.pop()
                break 
 
backtracking(0,init_board,scoreBoard)
print(correct)
```
