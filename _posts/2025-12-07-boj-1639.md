## 문제

- 행운의 티켓은 2N자리가 언제나 늘 붙어있다.
- 따라서 시작점을 어디로 잡아야 할지가 관건이다.(홀수인 경우도 있기 때문에)
- 아니면 분할정복으로 풀어야 할까???
- 분할정복으로 풀 수 있으면서도 부르트포스로 해결 가능할거 같다.
- 0~n자리 까지를 거꾸로 돌려 0~n/2의 합과 n/2부터 n까지의 합을 구하여 비교한다.
- 911113468 이런거는 어떻게 풀어야 하나….. 분할 정복으로 풀어야 할까

## 구현

- i : 0~n,k : i~n의 모든 경우의 수를 찾는다.
- j 는 (i+k)/2를 이용해 행운의 티켓의 자리는 2n이므로, 절반으로 n,n으로 나눠 각각의 자리의 합을 구해 이를 비교하여, k와 i의 차를 구하여 복권의 길이를 correct에 저장한다.
- 반복문을 모두 돌고 난 뒤, max\_element 함수를 이용하여 가장 큰 길이를 출력한다.

## 코드

```cpp
#include <iostream>
#include <string>
#include <vector>
#include <algorithm>
using namespace std;

int main() {
    string n;
    int save1 = 0;
    int save2 = 0;
    vector<int> correct;
    cin >> n;

    for (int i = 0; i < n.length(); i++) {
        for (int k = i + 1; k < n.length(); k += 2) {
            for (int j = i; j <= (i + k) / 2; j++) {
                save1 += (n[j] - '0');
                save2 += (n[i + k - j] - '0');
            }
            if (save1 == save2) {
                correct.push_back(k - i + 1);
            }
            save1 = 0;
            save2 = 0;
        }
    }

    if (correct.size() == 0) {
        cout << 0 << endl;
    } else {
        cout << *max_element(correct.begin(), correct.end()) << endl;
    }
    return 0;
}
```
