## 구현

- 이 문제는 a,b 배열이 주어지는데 a배열의 길이는 N, b배열의 길이는 2N이다.
- a 배열 내에서 같은 값을 계속 이어붙여 b배열의 값을 만들어내는 문제인데 간단하게 b배열에서 a배열의 값이 없는게 있으면 b배열을 만들 수 없고 있으면 b 배열을 만들 수 있다.
- 따라서, 처음에 b배열을 반으로 나눠 a배열과 비교한 뒤, 값이 다르면 a배열로 b배열을 만들 수 없으므로 NO를 출력한다.
- 같다면, 초반 b배열의 반을 제외한 나머지를 a배열과 SET함수를 이용하여 b배열에서 a배열의 차집합을 구하면 중복되지 않는 값이 남아있다면, NO를 출력 중복되는 값들만 있어 차집합의 값이 비어있다면 YES를 출력한다.
- 처음에는 브루트포스를 이용하여 구현하려 했으나, 시간제한 1초가 걸려있어 시간복잡도 O(N^2)으로는 풀어낼 수는 없었다.(파이썬의 한계일수도 있으나, PYPY3를 써본결과에도 풀리지 않아서 다른 문제로 풀었어도 시간제한이 1초라서 안풀렸을 가능성이 있을지도 모르겠다. C++을 썼더라면 가능했을지도 모르겠다.)
- 처음에 접근을 잘못해서 그런지 너무 많이 시간을 허비했다. 아직 문제 독해능력이 너무 약하다. 문제 이해력이 부족해 접근하는데 시간을 너무 많이 쓴다.
- 또한, 메모리 시간 제한을 읽는 연습을 해야한다. 시간복잡도 생각을 하지 않는다면, 이 문제를 초반에 풀었던 것처럼 처음에 되지 않는 경우에 집중하여 삽질하기 떄문이다. → 따라서, 삽질을 줄이는 연습을 해야한다.

## 코드

```python
n = int(input())
N = list(map(int, input().split()))
N2 = list(map(int, input().split()))
count = 0

if N == N2[:len(N)] :        
    a = set(N)
    b = set(N2[len(N):])
    if b - a :
        print("NO")
    else :
        print("YES")
else :
    print("NO")
```
