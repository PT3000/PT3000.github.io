## 구현

- 이 문제는 같은 길이의 다른 단어를 주고, 각 단어들의 거리를 키보드 자판에 떨어져 있는 거리만큼 구하여, 거리에 따라 단어를 정렬, 사전순에 따라 단어를 정렬하는 문제이다.
- 키보드 자판을 좌표로 계산하여 딕셔너리로 접근할 수 있게 각 알바뱃들을 키로 잡고 좌표를 value로 잡는다.
- 단어들을 키보드의 자판을 이용하여 거리는 구하는 방법은 떨어져 있는 가로의 길이 세로의 길이이다.
- 즉, \|x-y\| + \|x-y\| 이다.
- 각 단어들의 알파벳들의 떨어져 있는 거리를 구하여 더한 뒤, 단어와 좌표값을 리스트에 튜플로 묶어 저장한다.
- 저장한 값들을 람다식으로 거리순, 사전순으로 정렬한다.

## 코드

```python
keyboard = {
    'q': [0, 0], 'w': [0, 1], 'e': [0, 2], 'r': [0, 3], 't': [0, 4],'y': [0, 5], 'u': [0, 6], 'i': [0, 7], 'o': [0, 8], 'p': [0, 9],
    'a': [1, 0], 's': [1, 1], 'd': [1, 2], 'f': [1, 3], 'g': [1, 4],'h': [1, 5], 'j': [1, 6], 'k': [1, 7], 'l': [1, 8],
    'z': [2, 0], 'x': [2, 1], 'c': [2, 2], 'v': [2, 3], 'b': [2, 4], 'n': [2, 5], 'm': [2, 6]
}
correct = []
n = int(input())

for i in range(n) :
    a = list(input().split())
    correct = []
    for k in range(int(a[1])) :
        t = input()
        distance = 0
        for y in range(len(t)) :
            pos_a = keyboard[a[0][y]]
            pos_x = keyboard[t[y]]
            distance += abs(pos_a[0]-pos_x[0]) + abs(pos_a[1]-pos_x[1])
        correct.append((t,distance))
    correct = sorted(correct, key= lambda x : (x[1],x[0]))
    for a in correct :
        print(a[0], a[1])
```
