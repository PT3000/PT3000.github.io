- 아기상어는 자기와 작은 물고기를 먹을 수 있다.
- 아기상어는 자기와 같은 크기의 크기의 칸을 지나갈 수는 있지만, 먹을 수는 없다. ← 여기서 이게 문제
- baby > grpah\[nx\]\[ny\] 냐, baby ≥ graph\[nx\]\[ny\]냐
- 일단 자신의 크기와 같은 칸도 지나간다고 가정을 해보고 시작한다.
- 단, 물고기를 먹은것이 아니기 때문에, count를 하지 않는다.

## 문제점

- 그래프를 언제 0으로 만들 것이냐???
- 같은 거리에 있을때, 2개의 값이 동시에 있다. 그러나, 어느 것이 위쪽인지 아래인지 알 수 없다. 그렇기 때문에 어느 것을 0으로 만들어야 할지 모른다. ← 그래프가 멈추는 기준은 이러한 두 개의 경우가 발생할 때이긴 하다. 그럼 반복문이 끝나고 나서 0을 검증해야 하나? 하지만 순환하면서 0으로 만들어야 하는 경우도 있는거 아닌가???
- 아님 일단 0으로 만들고, 음…. 나중에 다시 추가해준다. 이건 좀…..

```python
from collections import deque

n = int(input())
graph = [list(map(int, input().split())) for _ in range(n)]
shark = [[i,j] for i in range(n) for j in range(len(graph)) if graph[i][j] == 9]
visited = [[0 for _ in range(n)] for _ in range(n)]

dx = [0,1,0,-1]
dy = [1,0,-1,0]
store = []
store2 = []
baby = 2
count = 0
answer = 0
graph[shark[0][0]][shark[0][1]] = 0
graph2 = graph.copy()
def bfs(x,y,graph,store,store2) :
    global visited
    global count
    global baby
    visited[x][y] = 0
    queue = deque()
    queue.append((x,y))
    while queue :
        x,y = queue.popleft()
        for i in range(4) :
            nx = x + dx[i]
            ny = y + dy[i]
            if 0 <= nx < n and 0 <= ny < n :
                if baby >= graph[nx][ny] and visited[nx][ny] == 0 : ## 아기 상어가 다른 물고기와 같은 경우에도 지나갈 수 있다.(이 물고기를 거쳐서 최단 거리로 갈 수도 있기 때문이다.)
                    visited[nx][ny] = visited[x][y] + 1
                    if baby > graph[nx][ny] > 0 and (nx,ny) not in store and visited[nx][ny] not in store2 :   ## visited가 같은 값이 먼저 들어가 있지 않아야 count 할 수 있다
                        count += 1
                        store.append((nx, ny))  ## 아기상어가 자기 자신보다 작을때만, store, store2를 더해준다.
                        store2.append(visited[nx][ny])
                        graph[nx][ny] = 0  ## 자기 자신보다 작을때만 빈 공간으로 만들어야 한다.
                    if baby == count:
                        baby += 1
                        count = 0
                    queue.append((nx,ny))

bfs(shark[0][0], shark[0][1], graph, store,store2)
while True :
    x,y = sorted([(x,y) for x,y in store if visited[x][y] == max(store2)], key=lambda x: (x[0],x[1]))[0]
    ## visited[x][y]가 제일 큰게, 우선이고 값이 같을 때, x,y 우선순위를 비교한다.
    if store.count(max(store2)) >= 2 :
        x2,y2 =  sorted([(x,y) for x,y in store if visited[x][y] == max(store2)], key=lambda x: (x[0],x[1]))[1]
        graph[x2][y2] = graph2[x2][y2]
    store = []
    store2 = []
    answer += visited[x][y]
    a = [k for i in graph for k in i if k > 0]
    visited = [[0 for _ in range(n)] for _ in range(n)]
    if not a or baby <= min(a) :
        break
    bfs(x, y, graph, store,store2)

print(answer)
```
