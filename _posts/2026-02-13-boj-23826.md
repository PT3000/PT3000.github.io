## 구현

- 알고보면 어려운 내용은 아니지만 문제의 내용을 되게 꼬아서 냈다.(내가 해석을 잘 못하는 이유도 있다.)
- 결정적인 실수를 한 것이 있는데, 와이파이 속도를 구할때 같은 방이라도 핫스팟 WIFI가 켜져 있으면, 공용 WIFI 전파를 방해하기 때문에 처음에는 자기 자신은 속도를 구할때 포함하지 않은 실수를 범했다. → WIFI 원리에 맞게 문제를 매우 잘만들었다는 생각이 들었다.
- N개의 방을 입력받고 두번째 줄에는 공용 WIFI가 있는 소학습실이 있다.
- 두번쨰 줄부터는 좌표값 X,Y를 입력받고 에너지의 크기를 입력받는다.
- 나머지는 방인데 먼저 기준점의 방을 잡은 뒤, 소학습실과 와이파이 세기를 구하고 나머지 방들과도 와이파이 세기의 합을 구하여 소학습실과의 와이파이 세기에서 이를 뺀 것이 와이파이 속도이다.
- 와이파이 세기 구하는 식은 MAX(0, P-(\|a-c\|+\|b-d\|)) 이다. → 여기서 P는 기준점을 잡은 방의 에너지(E)이다.
- 와이파이 속도가 0 이하일 경우에는 와이파이에 연결할 수 없기 때문에 각 방에서 와이파이 속도를 구하여 가장 큰 와이파이 속도의 값이 0 미만인 경우는 IMPOSSIBLE을 출력한다.
- 에너지가 0이 아니면, 핫스팟 WIFI가 켜져있고 0이면 WIFI가 켜져있지 않는데 이는 별로 중요하지 않다. → 와이파이 속도를 구할 때, 세기들의 합을 구하여 빼야 하는데, 핫스팟이 없더라도 방해받지 않는 값들을 포함시켜야 되기 때문이다.

## 코드

```python
n = int(input())
correct = []
room = []
sum = 0

X,Y,E = map(int, input().split())
for i in range(0,n) :
    a = list(map(int, input().split()))
    room.append(a)
    
for i in range(len(room)) :
    intensity = max(0,E-(abs(X-room[i][0])+abs(Y-room[i][1]))) 
    for k in range(len(room)) :
        sum += max(0,room[k][2]-(abs(room[i][0]-room[k][0])+abs(room[i][1]-room[k][1])))
    correct.append(intensity-sum)
    sum = 0

if max(correct) > 0 :
    print(max(correct))
else :
    print("IMPOSSIBLE")
```
