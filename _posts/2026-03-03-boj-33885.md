## 조건1

- c\_i: i번째 과목을 수강하여 얻을 수 있는 학점을 나타낸다.
- s\_i: 매주 i번째 과목이 진행되는 강의 횟수를 나타낸다.
- d\_\{i,j\}: 매주 i번째 과목의 j번째 강의가 열리는 요일을 나타낸다.
- h\_\{i,j\}: 매주 i번째 과목의 j번째 강의가 열리는 시각을 나타낸다. 강의는 h\_\{i,j\}시 정각에 시작해서 h\_\{i,j\}시 59분에 종료된다.

## 조건2

- 일부만으로 시간표를 구성했을 때, 졸업 요건인 M학점을 알고싶다.
- 수강하고자 한 과목들의 시간이 겹치지 않아야 한다.
- 이동시간은 고려하지 않는다.
- 과목을 백트래킹하여 졸업의 최소요건을 만족하면 바로 return 한다.

## 풀이

- 이 문제는 각 과목의 수강신청의 시간표 후보들 중에서 시간표 후보들이 겹치지 않게 선택하면서 졸업 최소 요건 학점인 M인 이상인 경우를 판단하는 문제이다.
- 각 수강신청의 과목들의 시간표가 다른 수강신청 과목들의 시간표와 겹치면 안되기 때문에 선택을 시도하고 되돌아오는 백트래킹(DFS)가 필요한 문제이다. → 분기점을 나누어서 최소 요건 학점인 M을 찾는 것이 핵심인 문제
- 학생들의 수강신청 정보를 리스트로 묶어, 각각의 학점에 관한 수강신청을 한번 더 묶어서 백트래킹을 돌렸다.
- 처음에는 요일, 시간을 따로 분리하여 기존에 선택한 수강신청 시간표와 비교하려 하였으나, 요일, 시간을 함께 비교하는 것이 더 간단하고 단순화하기 좋을것같아, (요일, 시간) 형태로 묶어서 검사했다.
- correct라는 리스트에 순회를 돈 리스트 k가 없으면, count를 해준다.
- count 값이 수강신청 과목의 과목의 수와 일치하면 백트래킹을 한다.(correct에서 k가 없을때의 경우를 순회하면서 count값이 해당 수강과목의 시간표 갯수와 일치하지 않으면  해당 수강신청 과목은 들을 수 없는 경우이기 때문에 correct 후보군에 올릴 수 없다. → 즉, 해당 분기점에서 이 수강과목은 들을 수 없는 상태, 따라서 다음 분기점으로 넘어갈 수 없다.)
- 이때 score의 값도 scores에서 해당 위치에 있는 scores의 값들을 추가하게 하는데 이 또한 백트래킹을 이용하여 분기점을 나누면서 score에 저장한다.
- 만약, 모든 수강신청의 과목들을 다 돌렸으면 return하여 다시 되돌아온다.
- return하면서, correct에 있는 값들을 지우게 되는데 이때 해당 수강신청의 시간표의 갯수만큼 correct.pop()을 해주고, score에 있는 값도 pop()을 해준다. → 해당 분기점의 점수가 필요 없기에 → score 또한 백트래킹을 돌린다.
- score 또한 백트래킹을 돌리면서 sum을 이용해 최소 점수인 M을 넘으면 yes를 출력하게 하고, M을 넘지 않으면 no를 출력하게 한다.

## 코드

```python
n,m = map(int, input().split())
a = []
b = []
scores = []
for i in range(n) :
    k = list(input().split())
    b.append([k[2:][i:i+2] for i in range(0,len(k[2:]),2)])
    a.append(k[1])
    scores.append(k[0])
score = []
correct = []
def backtraking(start) :
    global correct
    if sum(score) >= m :
        print("YES")
        exit(0)
    if start == n :
        return
    for i in range(start,n) :
        count = 0
        for k in b[i] :
            if k not in correct :
                count += 1
        if count == len(b[i]) :
            for t in b[i] :
                correct.append(t)
            score.append(int(scores[i]))
            backtraking(i+1)
            for _ in range(int(a[i])) :
                correct.pop()
            score.pop()
              
backtraking(0) 
print("NO")
```
