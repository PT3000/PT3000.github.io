## 문제 구성

- 남학생 수와 여학생 수는 각각 N명이다.
- A,B,C 3개의 출신학교로 구성되어있다.
- 남녀 짝을 서로 다른 학교출신으로 구성되어야 한다.
- 중요한 것은 출신만 다르되, 남녀 짝수만 같게하면 된다.(그렇게 하면 따로따로 구성되기에)

## 구현

- 이 문제는 그리디라고 생각된다.
- 남학생과 여학생을 분리하여 저장한다.
- 둘째 줄에 A초등남학생과 B초등여학생의 짝 수 \| A초등남학생과 C초등여학생의 짝 수
- 셋째 줄에 B초등남학생과 A초등여학생의 짝 수 \| B초등남학생과 C초등여학생의 짝 수
- 넷째 줄에 C초등남학생과 A초등여학생의 짝 수 \|  C초등남학생과 B초등여학생의 짝 수

## 잘못된 코드

```python
man = []
female = []
correct = False
result1 = [0,0,0]
result2 = [0,0,0]
compare = [[1,2],[0,2],[0,1]]

student = int(input())
for i in range(0,3) :
    a,b = map(int, input().split())
    man.append(a)
    female.append(b)

for i in range(0,3) :
    if man[i] == female[compare[i][0]] + female[compare[i][1]] :
        if female[i] == man[compare[i][0]] + man[compare[i][1]] :
            correct = True
            result1[i] = female[compare[i][0]]
            result2[i] = female[compare[i][1]]
            result1[compare[i][0]] = man[compare[i][0]]
            result1[compare[i][1]] = man[compare[i][1]]
    if correct :
        break

if correct :
    print(1)
    for i in range(3) :
        print(result1[i],result2[i])
        print(end='')
else :
    print(0)
```

- 이 코드의 문제는 한 남자의 그룹을 다른 여자의 그룹의 최대치로 묶으려 한다는 점이다.
- 최대치로 묶지 않고도 맞아떨어지는 경우도 있기 때문에 이 코드는 잘못됐다.

## 옳은 코드

```python
studentNum = []
correct = False

student = int(input())
for i in range(0,3) :
    a,b = map(int, input().split())
    studentNum.append(a)
    studentNum.append(b)

for i in range(1,studentNum[0]+1) :
    a = i
    b = studentNum[0] - a
    d = studentNum[5] - b
    c = studentNum[2] - d
    e = studentNum[1] - c
    f = studentNum[4] - e

    if a >= 0 and b >= 0 and c >= 0 and d >= 0 and e >= 0 and f >= 0 :
        correct = True
        print(1)
        print(a,b)
        print(c,d)
        print(e,f)
        break

if correct == False :
    print(0)
```

## 구현

- a학교 남자 그룹을 미지수로 잡고, 0부터 남자 그룹의 최대까지 반복문을 돌린다. 그런 다음 차례차례대로 다른 그룹의 수를 방정식을 세워 구한다.
- 구한다음, 짝인 경우가 0 이상인지 모두체크하여 모두 0이상이면 정답을 출력하고, 그렇지 않은 경우, 0을 출력한다.
- 이 문제는 방정식을 세우는게 관건인 문제였다.(너무 꼬아 생각했다.)
- 즉, 하나만 알면 나머지도 다 알 수 있다.
