## 구현

- 들어가는 피자는 최상단 입구부터 최하단 입구로 들어가기 때문에, 중간의 관의 지름의 넓이가 들어가는 관의 지름의 넓이가 그 밑의 관의 지름보다 작으면, 그 밑의 관의 지름이 아무리 커도 피자는 중간의 관에서 끊길 것이다.
- 따라서, 이를 이용하면 시간복잡도를 O(N)으로 줄일 수 있다.
- 예를 들어 관의 깊이가, `5 6 4 3 6 2 3` 면, 5 5 4 3 3 2 2 이런식으로 바꿀 수 있다.
- 벡터 2개를 생성하여, 관의 깊이도를 미리 받고, 다른 벡터에 관의 깊이도를 처음부터 끝까지 거꾸로 탐색하여, 더 높이 있는 관이 더 낮은관보다 숫자가 작으면, 낮은관의 숫자를 높이 있는 관의 숫자로 바꾼다.
- 바꾼 다음, 바꾼 관을 이용하여, 피자를 넣었던 지름을 이용하여, 순서대로 가장 낮은관부터 피자의 지름이 해당 관보다 작으면, 위로 올리고 크거나 같으면, 그 위치에 안착시킨다.
- 푸는 과정에서 조사한 피자를 지울 때, vector의 erase를 썼지만, 시간복잡도가 크기 때문에, deque의 시간복잡도 O(1)인 pop\_front를 사용했다.

## 느낀 점

- 62프로에서 ‘틀렸습니다’에서 막혀서 반례가 뭔지 계속 고민하고 있었다.
- 피자 개수가 피자를 세지 않은 갯수와 똑같다면, 0을 출력하도록 유도했다.
- 그렇지만, 로직을 이렇게 짜면, 0이 출력되어야 한다는 상황에 이 로직을 바꾸었다.
- 하지만, 왜 로직을 이렇게 바꿔야 작동이 되는지 직관적으로만 알 뿐, 논리적으로는 접근하지 못했다.
- 향후, 이 문제는 더 정밀한 분석이 필요하다. → 그래야 실력이 늘거라 생각한다.
- 오랜만에 푼 골드 문제이다. → 하지만, 푸는 과정을 봐버렸다.(어떻게 푸는지 감도 안잡혔기 때문에)
- 이 문제는 푸는 원리는 어렵지 않았지만, 시간복잡도에 대한 이해도가 더 필요하다고 생각한다.
- 따라서 시간복잡도의 원리를 이해해야겠다.

## 코드

```cpp
#include <iostream>
#include <vector>
#include <deque>

using namespace std;

int main() {
    int row = 0;
    int col = 0;
    int save = 0;
    int correct = 0;
    vector<int> tube;
    deque<int> pizza;

    cin >> row >> col;
    for (int i = 0; i < row; i++) {
        cin >> save;
        tube.push_back(save);
    }

    for (int i = 0; i < col; i++) {
        cin >> save;
        pizza.push_back(save);
    }

    for (int i = 0; i < row - 1; i++) {
        if (tube[i] < tube[i + 1]) {
            tube[i + 1] = tube[i];
        }
    }
    for (int m = row - 1; m > -1; m--) {
        if (tube[m] >= pizza.front()) {
            if (pizza.size() == 1) {
                correct = m + 1;
                break;
            }
            pizza.pop_front();
        }
    }
    if (pizza.size() == 1) {
        cout << correct << endl;
    } else {
        cout << 0 << endl;
    }
    return 0;
}

```
