## 구현

- 이 문제는 소인수분해를 해야할 N의 범위가 5,000,000이기 때문에 일반적으로 우리가 흔히 쓰는 소인수분해로 문제를 풀려면 시간복잡도가 O($$\sqrt{n}$$)이 나오기 때문에 시간초과가 뜰 것이다. 따라서 우리는 소인수분해를 풀 효율적인 알고리즘을 활용해야 한다.
- ‘에라토스테네스의 체’라는 소수를 구하는 알고리즘을 사용하는 것인데, 중요한 것은 체를 그냥 사용하는 것이 아닌, 활용하여 사용하는 것이다. → 본인은 이것을  그냥 사용하려 하였기 때문에 ㅈㄴ 삽질했다.
- 이 문제는 시간복잡도가 O(loglogN)로 대략 예상된다.
- 이 문제의 핵심 발상은 N의 범위가 5,000,000까지 제한됐으므로, N의 최소의 소인수를 5백만까지 일일히 다 저장하여 나중에 소인수분해를 할때, 1부터 5백만까지 N의 표를 참조하여 참조하는 순간, 시간복잡도는 O(1)로 줄일 수 있다.
- 소인수를 구하는 방법은 두가지가 있다. 소수거나, 아니면, 최소한의 N의 배수이거나 두가지로 나뉜다.
- 에라토스테네스의 체는 최소한의 배수로 차례차례 지나가면서 모든 N의 배수를 줄인 뒤, 나머지를 소수로 판정하여 소수를 뽑아내는 알고리즘이다.
- 따라서, 1부터 5백만의 최소 소인수들을 저장하여 구할 때,   N의 표에 들어가는 숫자를 0으로 초기화 시켜놓는다.
- 1부터 5백만까지 위치에 따른 위치의 값을 자기 자신으로 저장해놓는다. → 배수 부분을 제외한 소수들을 남겨놓기 위한 것
- 체의 알고리즘을 활용하여,  $$\sqrt{n}$$까지 배수들을 돌리면서 n의 배수에 있는 모든 숫자들은 최소 소인수가 n이기 때문에 n으로 바꾼다. → n의 배수를 돌릴때, 본인은 제외한 본인 다음의 배수부터 숫자들을 바꾼다.
- 배수를 다 돌리고 나면, 앞서 말한 것처럼 배수를 제외한 부분은 본인이 소수이기 때문에 미리 자기 자신을 소수라고 가정하여 값을 미리 넣어뒀으므로, 배수를 제외한 나머지 부분들은 자기 자신이 소수가 되어있을 것이다.
- 이렇게 구한다면 n의 범위가 5백만까지 제한되어 있는 소수 알고리즘은 효율적으로 구할 수 있다.
- 특정 숫자를 소인수분해할때, 나눗셈을 하되, 나눗셈을 한 값들은 n의 표를 참조하여 O(1)의 시간복잡도로 소인수들을 구할 수 있다.

## 코드(덜 개선됨)

```cpp
#include <iostream>
#include <vector>
#include <cmath>
using namespace std;

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(NULL);
    cout.tie(NULL);
    int n;
    int s;
    int k;
    vector<int> save;
    vector<int> min_prime(5000001, 0); //500만 이하의 소수들을 저장하는 곳

    cin >> n;

    for (int i = 0; i < n; i++) {
        cin >> s;
        save.push_back(s);
    }

    for (int i = 2; i < sqrt(5000000); i++) {
        if (min_prime[i] == 0) {
            min_prime[i] = i; //내 자신이 소수인 경우 소수로 갖는다.
        }
        for (int j = i * i; j < 5000001; j += i) {
            if (min_prime[j] == 0) {
                min_prime[j] = i; // 배열에 따른 소인수의 최소화
            }
        }
    }
    for (int i = sqrt(5000000); i < 5000001; i++) {
        if (min_prime[i] == 0) {
            min_prime[i] = i;
        }
    }

    for (int i = 0; i < save.size(); i++) {
        while (save[i] != 1) {
        k = min_prime[save[i]];
            cout << k << ' ';
            save[i] /= k;
        }
        cout << '\n';
    }


    return 0;
}


```
