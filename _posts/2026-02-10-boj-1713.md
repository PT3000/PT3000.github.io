## 구현

- 후보 찾는데에 조건이 많아 몇몇 조건들을 제대로 이해하지 못했다.(아무래도 문제 독해를 가장 못한게 이 문제를 푸는데 가장 오래 걸렸던 이유같다…..)
- 규칙은 다음과 같다.

1. 학생들이 추천을 시작하기 전에 모든 사진틀은 비어있다.
2. 어떤 학생이 특정 학생을 추천하면, 추천받은 학생의 사진이 반드시 사진틀에 게시되어야 한다.
3. 비어있는 사진틀이 없는 경우에는 현재까지 추천 받은 횟수가 가장 적은 학생의 사진을 삭제하고, 그 자리에 새롭게 추천받은 학생의 사진을 게시한다. 이때, 현재까지 추천 받은 횟수가 가장 적은 학생이 두 명 이상일 경우에는 그러한 학생들 중 게시된 지 가장 오래된 사진을 삭제한다.
4. 현재 사진이 게시된 학생이 다른 학생의 추천을 받은 경우에는 추천받은 횟수만 증가시킨다.
5. 사진틀에 게시된 사진이 삭제되는 경우에는 해당 학생이 추천받은 횟수는 0으로 바뀐다.

- 여기서 실수한 점은 3번의 규칙이다. 비어있는 사진틀이 없는 경우, 새로운 후보자가 나타났을 때 탈락자를 결정하는 비교 범위를 액자틀이 아닌, 전체 후보군으로 설정하는 오류를 범했다. 이로 인해, 사진틀 안의 최저 투표자가 전체 후보군 사이에서 최저 투표자가 아닌 경우, 교체 로직이 아예 건너뛰어졌다. 이로 인해 데이터 갱신이 제대로 이루어지지 않았다. 올바른 로직은 새로운 후보자가 들어오는 즉시 사진틀 안에서의 순위만을 따져 최소 후보자를 반드시 제거하고 그 빈자리에 새로운 후보자를 즉시 삽입했어야 한다.
- 학생 수와 추천 갯수를 연결하여 세야되기 때문에 딕셔너리를 활용하여 key를 학생 번호, value를 추천 갯수로 설정하여 연결하였다.(학생 수가 100명 이기에 1번부터 100명까지 추천 갯수는 0으로 초기화하여 설정)
- 액자틀의 최대갯수까지 나열된 후보자를 넣어주고 액자틀의 최대갯수를 넘는다면 현재 후보자가 액자틀에 있는 후보군의 명단에 있는지 확인하고 확인하면 액자틀의 후보자의 좋아요 갯수를 늘린다.(전체 후보자의 추천수와 이를 맞추기 위해서)
- 후보군의 명단에도 포함되지 않는다면, 액자틀 안의 최소 갯수의 후보군들을 찾는다.
- 가장 작은 후보군의 키들을 리스트에 담아 두개 이상 있다면, 오래된 후보군을 액자틀에서 제거하고 현재 후보자를 넣고, 하나면 그 후보자를 액자틀에서 제거하고 현재 후보자를 넣는다.
- 최종 후보자들을 정렬하여 출력한다.

```python
picture = int(input())
like = int(input())
number = list(map(int, input().split()))
picture2 = {} ## 액자틀
a = {} ## 학생 100명 후보추천수

for i in range(1,101) :
    a[i] = 0

for i in range(0,len(number)) :
    a[number[i]] += 1
    if len(picture2) < picture :
        picture2[number[i]] = a[number[i]]
    elif number[i] in picture2.keys() :
        picture2[number[i]] += 1 
    else :
        l = [k for k,v in picture2.items() if v == min(picture2.values())] ## 액자틀 안 가장 작은 후보군들의 키를 저장
        minPicture = min(picture2, key=picture2.get) ## 액자틀의 최소 후보자의 키값
        if(len(l) >= 2) : ## 만약, 가장 작은 후보군의 같은값인 키가 두개 이상 있다면 
           a[minPicture] = 0 ## 후보군 초기화
           l.remove(minPicture)
           del picture2[minPicture] ## 액자틀의 키 삭제
           picture2[number[i]] = a[number[i]] ## 같은 값이었던 후보자 키 추가
        else :
           a[minPicture] = 0 ## 후보군 초기화
           del picture2[minPicture] ## 액자틀의 키 삭제
           picture2[number[i]] = a[number[i]]

print(*sorted(picture2))
```
