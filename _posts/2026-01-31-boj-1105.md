## 구현

- 두 수 L과 R이 주어지면, L을 기준으로 L보다는 같거나 크되, R보다는 작거나 같아야 한다.
- 따라서 L을 기준으로 L에 8이 들어있으면, L에 들어있는 8이 있는 기준까지 잡고 R보다 작게 8의 자릿수를 추가하여 가장 적은 8의 자릿수대를 찾는다.
- 만약 L에 8이 없다면 0을 출력한다. → L은 작거나 같으므로 L이 만약 8이 포함되어 있지 않다면, L 그자체가 8이 없는 가장 작은 수다.
- 만약 L에 8이 있다면 8이 붙어 있는 경우에는 L을 출력하면 된다.
- 8808 8810처럼 만약 L에서 8이 띄어져 있는 경우라면8808보다 더 큰 8810부터는 8이 2개이다.

## 풀이

- L에 8이 포함되어 있지 않으면 0을 바로 출력한다. → 이 문제는 L ≤ K ≤ R 중에서 K가 8을 가장 적게 가지는 수 이므로, 만약 L에 8이 포함되어 있지 않다면 L 그자체가 최소이기 때문에 무조건 0이다.
- 만약 8이 포함되어 있다면, L에서 8을 1의 자리수부터 차례대로 검사한다.
- 만약 8이면 그 자리를 기준으로 슬라이스 한 다음 1을 더하여 자릿수에 따라 9 \* (10 \*\* N) 승을 문자열 형식으로 붙인다. → 8을 지우기 위해서 가장 최솟값인 9의 자릿수를 구하는 것이다.
- 구한 값 R과 비교하여 R보다 작거나 같은지 비교한다.
- 작거나 같으면 correct에 저장하고 만약 R보다 크다면 조건에 부합하지 않으므로, 반복문을 종료한다.
- 그리하여 correct에 들어있는 ‘8’의 개수를 출력한다.

## 코드

```python
l,r = input().split()
correct = l
if '8' in l :
    for i in range(0,len(l)) :
        if l[-(i+1)] == '8' :
            if int(l[:-(i+1)] + str(9 * (10 ** i))) <= int(r) :
                correct = l[:-(i+1)] + str(9 * (10 ** i))
            else :
                break
    print(str(correct).count('8'))
else :
    print(0)

```
