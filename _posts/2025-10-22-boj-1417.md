- 이 문제는 시뮬레이션, 우선순위 큐 혹은 그리디 알고리즘으로 풀 수 있는거 같다.
- 시뮬레이션을 사용한다면 상당히 복잡할것 같아, 우선순위 큐 혹은 그리디 알고리즘으로 풀어본다.

### 시뮬레이션으로 풀기

- 후보1을 제외한 채 나머지 후보들을 탐색한다.
- bigNum이라는 현재로서 가장 큰 후보의 인덱스 위치를 기억하는 함수를 설정한다.(bigNum은 처음에 0으로 초기화하여, 후보1과 비교하게 한다.
- 비교하여  가장 큰 후보군을 찾으면 count에 1을 더하고 가장 큰 후보군에서 1을 뺀다. (투표권을 빼앗은 횟수)
- 계속 반복하면서  count에 후보1을 더하여, 현재로서 가장 큰 후보군보다 크게 되면, 반복문을 종료한다.(현재로서 가장 큰 후보군보다 크게 된다면, 더이상 투표권을 빼앗을 필요가 없기 때문)

## 풀이

```cpp
#include <iostream>
#include <vector>

using  namespace std;
int main() {
    int n = 0;
    int count = 0;
    int bigNum = 0;
    bool winner = false;

    cin >> n;
    vector<int> v(n);

    for (int i = 0; i < n; i++) {
        cin >> v[i];
    }

    if (n == 1)
        cout << "0" << endl;
    else {
        for (int i = 1;i < n;i++) {
            if (v[0] > v[i]) {
                winner = true;
            } else {
                winner = false;
                break; //한번 false면 영원히 아웃, winner가 최고치가 아니기 때문
            }
        }
        if (winner == false) {
            while (1) {
                for (int i = 1; i < n;i++) {
                    //여기서 후보 1은 제외
                    if (v[bigNum] <= v[i]) {
                        bigNum = i; //가장 큰 수의 위치를 기억
                    }
                }
                if(v[0] + count  > v[bigNum]) {
                    break;
                }
                count += 1;
                v[bigNum] -= 1;
            }
        }
        cout << count << endl;
    }
    return 0;
}
```
